# Markdown テーブル クイック ジェネレータ

行数・列数を指定してGUIでセルを直接編集し、Markdownテーブルを即時生成・コピーできるツール。

## 機能
- 行数（1〜10）・列数（1〜8）のスピナー入力（±ボタン付き）
- GUIで各セルをinput要素で直接テキスト編集
- ヘッダー行を青でハイライト表示
- 各列のアライン（左/中央/右）設定
- 列幅を自動パディングして整形されたMarkdown生成
- 生成Markdownのリアルタイムプレビュー
- クリップボードへのコピーボタン（成功フィードバック付き）
- クリアボタン
- XSSエスケープ（escapeHtml）適用済み

## 技術
- Vanilla JS + Tailwind CSS CDN
- localStorage（非使用）
